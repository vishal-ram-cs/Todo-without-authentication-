# Todo-without-authentication-
# Todo Application

This is a simple Todo application built to learn Spring Boot without implementing authentication.

## Features
- Create a task
- Update a task
- Delete a task
- Toggle task completion status

## Technologies Used
- Spring Boot
- HTML
- CSS

## Purpose
The goal of this project was to understand the basics of:
- Spring Boot
- MVC architecture
- CRUD operations
- Backend and frontend integration

The next step is to build a Todo application with authentication and authorization using Spring Security.
